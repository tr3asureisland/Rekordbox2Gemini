<h3 align="center">🔁 RIESPORTI? RIPREMI. TUTTO QUI. 🔁</h3>

<details>
<summary><b>🔓 Prima apertura: il computer fa storie? Clicca qui</b></summary>
<br>

Il programma non è firmato, quindi la prima volta il sistema chiede conferma:
- **Windows**: *Ulteriori informazioni* → *Esegui comunque*.
- **Mac**: aprilo una volta, poi *Impostazioni di Sistema* → *Privacy e sicurezza* → **Apri comunque**.
  Se chiede l'accesso ai "volumi rimovibili", consenti.

</details>

<h2 align="center"><img src="immagini/h5-it.png" height="44" alt="PLAYLIST PAZZE"></h2>

<p align="center">Premi <b>PLAYLIST PAZZE</b> e il programma inventa playlist <code>CRAZY-…</code> con i brani della tua penna.</p>

| | | |
|:---:|---|---|
| 🎲 | **Casuali** | 20 brani a caso, quante playlist vuoi |
| 🐢 | **80–105 BPM** | dal più lento al più veloce |
| 🎡 | **Camelot** | 20 brani in catena con tonalità compatibili |
| 👻 | **Le Dimenticate** | 20 brani mai suonati |
| ⭐ | **5 Stelle** | il meglio del meglio |
| 🃏 | **JOKE-** | mescola i brani tra le tue playlist. **Fallo a un amico.** |

<p align="center"><sub><b>Cancella CRAZY</b> le toglie tutte · solo mp3 e wav: il Gemini non legge altro nelle playlist</sub></p>
